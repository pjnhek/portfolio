### Primitive 1: `Section` (FOUND-08, UI-SPEC.md §1)

Props (TypeScript):
- `id: string` — anchor id, e.g. `"about"`
- `number: string` — `"01"` through `"05"` (no trailing dot — NumberedHeading adds it)
- `title: string` — `"About"`, `"Experience"`, etc.
- `children: React.ReactNode`

Renders `<section id={id} className="py-16 md:py-24"><div className="mx-auto max-w-2xl px-6 md:px-12"><NumberedHeading number={number}>{title}</NumberedHeading>{children}</div></section>`.

### Primitive 2: `NumberedHeading` (FOUND-07, FOUND-08, D-06, UI-SPEC.md §2)

Props (TypeScript):
- `number: string` — `"01"` (no trailing dot)
- `children: React.ReactNode`
- `as?: "h1" | "h2"` — defaults to `"h2"`

Renders `<{as} className="mb-8 flex items-baseline gap-2 md:mb-12">` containing:
- `<span className="font-mono text-[length:var(--text-caption)] text-[color:var(--color-ink-muted)] tabular-nums">{number}.</span>` (the literal dot is here; do NOT pass `"01."` as the prop)
- `<span className="text-[length:var(--text-heading)] font-medium tracking-[-0.01em] text-[color:var(--color-ink)]">{children}</span>`

### Primitive 3: `Tag` (FOUND-08, UI-SPEC.md §3)

Props (TypeScript): `{ children: React.ReactNode }`.

Renders `<span className="inline-flex items-center rounded-sm border border-[color:var(--color-rule)] px-3 py-1 font-mono text-[length:var(--text-caption)] text-[color:var(--color-ink)]">{children}</span>`.

### Primitive 4: `ExternalLink` (FOUND-08, UI-SPEC.md §4)

Props (TypeScript):
- `href: string`
- `children: React.ReactNode`
- `showGlyph?: boolean` — defaults to `true`

Renders `<a href={href} target="_blank" rel="noopener noreferrer" className="underline decoration-1 underline-offset-[3px] hover:decoration-2 focus-visible:outline focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-[color:var(--color-ink)]">{children}{showGlyph && <span aria-hidden="true" className="ml-1 align-baseline font-mono text-[0.85em]">↗</span>}</a>`.

The trailing glyph is `↗` (U+2197 NORTH EAST ARROW) — UI-SPEC.md `## Color` "Accent reserved for" #1 locks this. NOT `→`.

### Primitive 5: `ArchitectureDiagram` (FOUND-08, D-08, UI-SPEC.md §5)

Props (TypeScript):
- `src: string`
- `alt: string` — REQUIRED (TypeScript enforces — NOT optional per D-08)
- `caption?: string`

Renders a `<figure className="my-8 md:my-12">` containing either (a) for `.svg` sources, a passthrough `<img src={src} alt={alt} className="h-auto w-full border border-[color:var(--color-rule)]" />` with `// eslint-disable-next-line @next/next/no-img-element` directly above the `<img>` (intentional — RESEARCH.md Pattern 7 explains why `next/image` is wrong for SVG), or (b) for raster sources, `<div className="relative aspect-[16/9] w-full border border-[color:var(--color-rule)]"><Image src={src} alt={alt} fill className="object-contain" /></div>`. Branch on `src.toLowerCase().endsWith(".svg")`. If `caption` is provided, render `<figcaption className="mt-3 font-mono text-[length:var(--text-caption)] text-[color:var(--color-ink-muted)]">{caption}</figcaption>` after.

### `lib/env.ts` shape (FOUND-10, RESEARCH.md Pattern 6)

Module structure:
1. `import { z } from "zod";`
2. `const schema = z.object({ NEXT_PUBLIC_SITE_URL: z.string().url().default("https://pjnhek.com") });`
3. `const parsed = schema.safeParse(process.env);` at module-top (NOT inside a function — RESEARCH.md Pitfall 5).
4. On `parsed.success === false`: `console.error("❌ Invalid environment variables:", parsed.error.flatten().fieldErrors);` then `throw new Error("Invalid environment variables. See above.");`.
5. `export const env = parsed.data;` (typed via Zod 3 type inference).

Notes:
- `.default("https://pjnhek.com")` keeps Phase 1 builds green when the env var is unset; Phase 4 removes the default after setting `NEXT_PUBLIC_SITE_URL=https://pjnhek.com` in Vercel production env.
- Use only Zod 3 APIs (`safeParse`, `.flatten().fieldErrors`). Pin remains `zod@^3.23` from Plan 01.

### Forbidden / banned in this plan

- `"use client"` anywhere — Phase 1 stays zero client islands per RESEARCH.md `## Architectural Responsibility Map`. All five primitives are pure Server Components.
- Hard-coding the `"01."` prefix anywhere outside `NumberedHeading`. `Section` passes `number="01"` (no trailing dot); `NumberedHeading` renders the dot.
- Adding client-side interactivity (`useState`/`useEffect`/`onClick`/event handlers) to any primitive.
- `next/image` for SVG sources in `ArchitectureDiagram` — passthrough `<img>` is correct. The intentional ESLint disable line must be line-scoped (above the `<img>`), NOT file-level.
- Lucide icons — installed but not imported in Phase 1 (Phase 2's Contact section is the first lucide use per CLAUDE.md / UI-SPEC.md).
- Any link target other than `https://github.com/pjnhek` for the ExternalLink demo (UI-SPEC.md `## Page Composition` #4 locks this URL).
- `mailto:` link in Contact (Phase 2 owns SEC-06).
- Footer, nav, breadcrumb (UI-SPEC.md `## Page Composition` excludes both from Phase 1).
- A `_placeholder.svg` heavier than ~1.5 KB (keep it a stub; do NOT base64-encode an exported design-tool asset).
- Reading `process.env.NEXT_PUBLIC_SITE_URL` directly in `app/layout.tsx` after this plan — `env.NEXT_PUBLIC_SITE_URL` is the only allowed read path.
