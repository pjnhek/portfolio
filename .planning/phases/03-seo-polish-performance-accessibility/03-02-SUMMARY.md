## What Was Built

**src/app/icon.tsx** — 32×32 JN monogram favicon generated via `ImageResponse`. Loads Geist-Regular from the bundled TTF in `node_modules/next/dist/compiled/@vercel/og/`. All styles are inline hex literals (`#fafafa` paper, `#0a0a0a` ink) — Satori cannot resolve CSS custom properties. Font size 14, letter-spacing -0.02em, centered layout. Exports `size = { width: 32, height: 32 }` and `contentType = "image/png"`.

**src/app/apple-icon.tsx** — Identical structure to icon.tsx, exports `size = { width: 180, height: 180 }` with `fontSize: 72` to remain legible at iOS touch-icon dimensions.

**src/app/favicon.ico** — Deleted. The `create-next-app` scaffold artifact coexisted with `icon.tsx`, creating a redundant second icon request. Modern browsers prefer the PNG generated by `icon.tsx`.

**src/app/not-found.tsx** — Server Component (no `"use client"` directive). Renders D-404-01 copy: big "404" mono label, "404" display heading, "This page wandered off. Here's the way back." paragraph, and a `← Back to home` Link with the canonical focus-ring string (`focus-visible:outline focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-[color:var(--color-ink)]`). Uses `max-w-2xl px-6 py-24 md:px-12` container matching the /uses page pattern. No `usePathname` (would require `"use client"` — violates SEC-07).

**src/app/sitemap.ts** — Returns `MetadataRoute.Sitemap` with 6 entries: home (priority 1), /uses (priority 0.8), and all 4 project slugs from `getAllProjects()` (priority 0.7, changeFrequency "monthly"). URLs are derived from `site.baseUrl` (defaults to `https://pjnhek.com`).

**src/app/robots.ts** — Returns `MetadataRoute.Robots` allowing all user agents with `allow: "/"` and referencing `${site.baseUrl}/sitemap.xml`. Build emits static `/robots.txt`.

**src/components/primitives/ArchitectureDiagram.tsx** — One-line patch: added `fetchPriority="high"` to the raster `<Image>` branch (line 52). The deprecated `priority` prop is absent (Next.js 16 breaking change). The SVG branch is unaffected.
